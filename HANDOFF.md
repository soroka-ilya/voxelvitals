# HANDOFF.md — VoxelVitals

## 1. Что сделано
- Разработана и протестирована полнофункциональная платформа мониторинга и телеметрии игровых серверов Minecraft (Java и Bedrock Edition) — **VoxelVitals**.
- **Умный резолвер алиасов (`AliasService`):**
  - Пользователю достаточно ввести короткое название: «2b2t», «hypixel», «cubecraft», «wynncraft», «donutsmp», «minemen», «gommehd», «manacube», «vimeworld» — бэкенд автоматически разрешает его в канонический домен (`2b2t.org`, `mc.hypixel.net`).
  - Поддержка разделителей и пробелов (`2b 2t` -> `2b2t.org`, `donut smp` -> `donutsmp.net`).
  - Поддержка портов (`hypixel:25565` -> `mc.hypixel.net:25565`), локальных серверов (`localhost`) и IPv6-адресов.
  - Автоматический TLD-fallback для неизвестных имен без точки (`.net`, `.org`, `.com`).
- **Живой интерактивный автокомплит (`/api/suggestions`):**
  - При вводе в строке поиска выпадает быстрое выпадающее меню в темной теме с логотипами, жанровыми бейджами и доменами серверов.
  - Поддержка навигации стрелками клавиатуры и санитизация HTML.
- **Категоризированный каталог популярных сетей:**
  - Вкладки фильтрации по жанрам прямо на главной странице: **Все**, **Анархия и Выживание**, **Мини-игры**, **MMORPG**, **PvP**.
  - Карточки серверов с логотипами, описанием, бейджами жанров и кнопкой **«Копировать IP»** в один клик с микроанимацией «Скопировано!».
  - Прямой переход в аналитику и 24-часовой график онлайна.
- **Сетевое ядро опроса (`pinger.py`):** опрос серверов через библиотеку `mcstatus` с поддержкой TCP Server List Ping, UDP RakNet query и автоматического разрешения DNS SRV записей.
- **Парсер и санитайзер MOTD (`motd_formatter.py`):** конвертация кодов Minecraft (`§0`-`§f`, стили `§l`, `§o`, `§n` и Hex-цвета `&#RRGGBB`) в безопасный HTML с защитой от XSS.
- **Генератор динамических SVG-бейджей (`badge_service.py` и `/api/badge/{address}.svg`):** векторные Shields.io-совместимые бейджи с HTTP-кэшированием для вставки в GitHub README, на сайты и в Discord.
- **Time-Series хранилище на SQLite (WAL-режим):** автоматический фоновый поллер и запись 24-часовой истории онлайна и задержки.
- **Тесты:** написан и пройден расширенный набор из **37 автоматизированных тестов** (`pytest -v`, 100% pass за 1.02с).
- **Дизайн по правилам `anti-vibecoding`:** темный глубокий сланец (`#0c0f17`), технические шрифты `Plus Jakarta Sans` и `JetBrains Mono`, скелетон-лоадеры, страницы Privacy Policy / Terms of Service.

---

## 2. Принятые решения
- **Максимальное удобство ввода:** объединение алиас-словаря с живым выпадающим автокомплитом и TLD-fallback.
- **Каталог на главной:** интерактивные вкладки жанров без перезагрузки страниц на чистом JavaScript/HTMX.
- **Копирование IP:** поддержка Clipboard API с отказоустойчивым fallback на `document.execCommand` для любых браузеров.
- **Стабильность и тесты:** 37 тестов покрывают все сценарии нормализации, парсинга, поиска и API-эндпоинтов.
