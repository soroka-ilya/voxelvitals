# HANDOFF.md — VoxelVitals

## 1. Что сделано
- **Устранен скачок скелетона (Zero Layout Shift):** скелетон загрузки перенесен непосредственно в целевой контейнер `#search-result`, добавлен обработчик `htmx:beforeRequest` для бесшовной плавной подстановки на точное место финальной карточки без прыжков верстки.
- **Интегрированы настоящие иконки серверов:** каждый сервер каталога и автокомплита теперь отображает реальную иконку сервера (через высокоскоростной кэш-прокси `https://api.mcstatus.io/v2/icon/...` с отказоустойчивым fallback на векторный SVG).
- **Масштабно расширен автокомплит и универсальный поиск:**
  - База расширена до 60+ топовых мировых и СНГ серверов (ReallyWorld, HolyWorld, FunTime, MST Network, MineBlaze, DexLand, SunRise, Hive Bedrock, Lifeboat, NetherGames, 6b6t, 9b9t, Constantiam, Lifesteal SMP, Jartex, Pika и др.).
  - Добавлен универсальный динамический fallback: 100% пользовательских запросов (любые произвольные домены или IP) сразу генерируют кликабельную подсказку с автоопределением издания.
- **Интерактивные карточки каталога без лишних кнопок:**
  - Кнопка «Опросить» удалена.
  - Вся карточка или имя сервера теперь кликабельны и ведут на `/server/{address}` (с сохранением режима `?bedrock=true`).
  - Кнопка «Копировать IP» изолирована с `stopPropagation`, чтобы копирование не вызывало переход.
- **Продвинутая панель фильтров с мультивыбором:**
  - Переключатель изданий: `[ Все издания ] [ Java ] [ Bedrock ]` вынесен в фильтры и синхронизирован со строкой поиска.
  - Мультивыпадающий список категорий (Анархия и Гриф, Мини-игры, MMORPG, PvP и Дуэли, Выживание/SMP).
  - Мультивыпадающий список версий с поддержкой **Minecraft 1.21.x Tricky Trials (Latest)**, 1.20.x, 1.16.5, 1.12.2, 1.8.9.
  - Кнопка «Сброс» и пустое состояние при отсутствии совпадений.
- **Исправлена навигация Bedrock:** переходы из каталога и карточки теперь жестко сохраняют флаг `?bedrock=true`, добавлено автоопределение Bedrock-узлов.
- **Удален блок «Quick test»** с главной страницы для более чистого минималистичного вида.
- **Исправлен блок Online Player Sample:** убраны пустые нули `00000000...` анонимизированных UUID; теперь отображаются скины/головы игроков с никами и статусом «Активен».
- **Редизайн Message of the Day (MOTD):** оформлен в стиле аутентичного мультиплеерного меню Minecraft с глубоким фоном, неоновым свечением цветов, версионным бейджем и кнопкой «Копировать MOTD».
- **Тесты:** все **42 теста** проходят успешно (`pytest -v`, 100% pass).

## 2. Принятые решения
- **Бесшовный UX поиска:** мгновенный рендеринг скелетона в целевой слот устраняет разницу в координатах до и после ответа сервера.
- **Динамический синтез подсказок:** даже если сервер отсутствует в каталоге, автокомплит синтезирует прямой узел.
- **Мультифильтрация на стороне клиента:** мгновенная фильтрация без дополнительных сетевых задержек.
