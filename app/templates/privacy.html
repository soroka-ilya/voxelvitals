Privacy Policy

Last updated: October 2026

1. Information We Collect

VoxelVitals provides public status monitoring for Minecraft multiplayer servers. We interact exclusively with publicly accessible network ports exposed by game server administrators via standard Server List Ping (TCP) and RakNet query (UDP).

2. Server Telemetry Data

When an address is submitted or tracked, we store:

  • Server address, port, and detected edition (Java or Bedrock).
  • Concurrent player count and configured capacity.
  • Network ping latency in milliseconds.
  • Public MOTD message and server icon.

3. Visitor Privacy & Tracking

We do not use tracking cookies, analytics pixels, or commercial ad networks. We do not sell or trade user data. Server telemetry records are automatically pruned after 24 hours.

4. Contact & Inquiries

For privacy concerns or to request removal of a server address from public tracking, contact the repository maintainers on GitHub.
