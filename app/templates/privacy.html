Privacy Policy

Last updated: November 2026

1. Zero Personal Data Processing

VoxelVitals is a strictly read-only public status monitor for Minecraft multiplayer servers. The website does not offer user accounts, registration, forms, comments, reviews, voting, or interactive user-to-user messaging, and does not collect, store, or process personal data.

2. Server Telemetry Only

We query publicly exposed game server ports (TCP Server List Ping and UDP RakNet) and store solely impersonal technical server metrics:

  • Server address, port, and edition (Java or Bedrock).
  • Aggregate player counts and slot capacity.
  • Network ping latency in milliseconds.
  • Public server MOTD and icon.

3. No Analytics, Trackers, or External CDNs

VoxelVitals does not use visitor identifiers, analytics cookies, IP logging databases, third-party advertising pixels, or external Google Fonts/CDN embeds. Only an optional functional UI cookie (vv_lang) is set when you manually switch interface language, and theme/launcher preferences remain strictly in your browser's local storage.
